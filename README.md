# 르노 그랑 콜레오스 장기렌트 — SECTION 01–06 시안

React.js + TypeScript + Vite + GSAP 기반의 랜딩페이지 디자인 소스입니다.
사용자가 제공한 **실제 그랑 콜레오스 차량 사진과 컬러별 이미지 5종**이 포함되어 있습니다.

## 실행 방법

Node.js 20.19+ 또는 22.12+ 환경에서 실행하세요.

```bash
npm install
npm run dev
```

터미널에 표시되는 로컬 주소(일반적으로 `http://localhost:5173`)를 브라우저에서 열면 됩니다.

## 프로덕션 빌드

```bash
npm run build
npm run preview
```

## 주요 파일

- `src/App.tsx`: 반응형 헤더, 히어로, 장기렌트 장점, 디자인·성능 섹션 및 GSAP 애니메이션
- `src/components/EstimateSection.tsx`: PC 좌측 컬러 스튜디오 / 우측 장기렌트 조건 선택 및 FAQ 이동 버튼
- `src/components/ReviewsSection.tsx`: SECTION 05 반응형 카드 슬라이더 (후기 원문 제공 전 빈 카드 15개)
- `src/components/ContactSection.tsx`: SECTION 06 FAQ 5개
- `src/consultation.ts`: SECTION 04의 장기렌트 조건 상태 및 기본값
- `src/contact.css`: SECTION 06 FAQ 반응형 스타일
- `src/services/rentalQuote.ts`: 견적 요청/응답 타입과 향후 렌트사 요율 API 연결 지점
- `src/styles.css`: PC·태블릿·모바일 스타일
- `src/estimate.css`: SECTION 04 컬러 스튜디오·견적 구성 스타일
- `public/assets/grand-koleos-satin-nocturne-blue.webp`: 사용자 제공 실제 차량 이미지
- `public/assets/{새틴 유니버스 화이트,클라우드 펄,메탈릭 블랙,어반 그레이}.webp`: 사용자 제공 컬러별 실제 차량 이미지
- `public/assets/grand_koleos_*.webp`: 사용자 제공 외관·실내·주행 관련 실제 차량 사진 중 SECTION 03에 사용한 5장
- `index.html`: 검색용 문서 제목·설명, 기본 Open Graph 메타, 이미지 프리로드·폰트 CDN 사전 연결

## 개발 범위

현재 제작 범위는 **SECTION 01 Hero, SECTION 02 장기렌트 장점, SECTION 03 차량 디자인·성능, SECTION 04 컬러 스튜디오 및 견적 조건 구성, SECTION 05 고객 후기 소개 영역, SECTION 06 FAQ**입니다.

SECTION 04는 PC 2열 구성(좌측 컬러 스튜디오, 우측 견적 설정)이며, 두 카드는 같은 높이로 정렬하고 내부 세로 스크롤은 사용하지 않습니다. 색상 전환, 드롭다운 방식 4종 트림(테크노·아이코닉·아이코닉 4WD·에스프리 알핀), 계약기간(3/4/5년), 연간 주행거리(1만/2만/3만km/무제한), 보증금·선납금(각 0/10/20/30%) 선택과 FAQ 이동 버튼을 제공합니다. 기본 조건은 5년·연 2만km·보증금 0%·선납금 10%입니다. 파워트레인, 만기 방식, 우측 조건 요약 카드 및 복사 기능은 의뢰에 따라 제거했습니다.

**확정된 렌트사 요율이 연동되지 않아 월 렌트료를 계산하거나 표시하지 않습니다.** 차량가격만으로 보험료·잔존가치·금융비용이 포함된 실제 장기렌트료를 산출하지 않습니다. API 및 실제 상담 신청도 아직 연동되지 않았습니다. 색상 이미지는 트림별 휠·그릴의 정확한 조합을 보장하지 않습니다.

SECTION 03 하이브리드 E-Tech 성능 수치는 르노코리아 공식 자료에 근거합니다. 복합연비 15.7km/L는 techno 19인치 기준이며, 특정 이미지에는 별도 트림이나 옵션이 표현될 수 있습니다.

SECTION 05는 미니멀 카드형 고객 후기 슬라이더입니다. PC에서는 3개, 태블릿에서는 2개, 모바일에서는 다음 카드 일부가 보이는 1개 카드로 반응하며 좌우 버튼·터치 스와이프·키보드 방향키로 이동할 수 있습니다. 고객 후기 원문은 추후 제공받을 예정이므로 현재는 15개의 카드에 텍스트 없는 장식용 빈 레이아웃만 배치했습니다. 확인되지 않은 고객 이름·별점·인용문은 표시하지 않으며, 실제 후기가 제공되면 해당 카드에 반영할 수 있습니다.

SECTION 06은 FAQ 5개만 유지합니다. 사용자가 표시한 기존 CONSULTATION 소개·상담 정보 입력·선택 조건 요약 전체 영역은 삭제했습니다. FAQ는 접근 가능한 단일 펼침 아코디언으로 구현했으며, 상단 메뉴 및 SECTION 04 하단 버튼으로 이동할 수 있습니다. 실제 상담 신청·DB 연동은 구현되어 있지 않습니다.

## 6단계 기술 최적화

- 개발용 `디자인 시안` 문구를 브라우저 제목과 검색 설명에서 제거하고, 제공 중인 기능에 맞는 SEO 문구 및 기본 Open Graph 정보를 설정했습니다.
- 최상단에 키보드용 본문 바로가기 링크를 추가했습니다. 모바일 메뉴는 연결된 내비게이션을 명시하며 `Esc` 키로 닫힙니다.
- 사용자가 동작 줄이기를 설정한 경우 버튼으로 섹션을 이동할 때 부드러운 스크롤을 강제하지 않습니다.
- 차량 이미지는 기존 WebP 포맷, 크기 속성, 첫 화면 이미지 사전 로딩 및 하단 사진 지연 로딩을 유지합니다.
- **정식 도메인이 확정되지 않아 canonical URL 및 절대 URL이 필요한 공유 이미지는 아직 설정하지 않았습니다.** 운영 공개 전 실제 도메인·대표 이미지를 확정해야 합니다.

SECTION 02의 설명은 일반적인 장기렌트 특징을 안내하며 특정 계약조건이나 무보증 이용, 보험·세금 포함 범위를 보장하지 않습니다.

실제 광고 사용 전 차량 이미지의 상업적 사용 권한과 브랜드 표기를 확인해주세요.
